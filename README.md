# YYC Story

A game by **Hassan Ali**, set in the real City of Calgary. You're a 15-year-old newcomer; each mission teaches a City service: Calgary Transit, 311, the library, recreation and Fair Entry, parks and pathways, finding help, and voting.

Play: https://hassanaliarshad110.github.io/yyc-story/ (test version)
